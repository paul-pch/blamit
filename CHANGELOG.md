# Changelog

## 0.2.0

- Browse a file's history: Open Previous / Next Revision, with editor title buttons and `Alt+,` / `Alt+.`. Inline blame works in those views too.

## 0.1.1

- Current line blame (author, relative date, commit summary).
- Hover with full commit message and links to the commit and MR/PR.
- Commands: Open Commit, Open MR/PR, Copy SHA, Set API Token.
- GitHub, GitLab and Gitea/Forgejo support, including self-hosted instances.
- MR/PR lookup from commit messages, with API fallback when a token is set.
- Translations: English, French, German, Italian, Spanish.
